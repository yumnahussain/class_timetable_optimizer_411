# UIC CS 411: Artificial Intelligence
## Project 2: University Class Scheduling & Timetable Optimizer (CSP) — Starter Code

This repository contains the starter files, relational datasets, report template, and guidelines for **Project 2: University Class Scheduling (Constraint Satisfaction Problem)**.

---

## Directory Structure

```text
.
├── app.py                      # Main entry point containing studentscheduler()
├── data/                       # Relational CSV datasets
│   ├── courses.csv             # Course catalog, instructors, and room requirements
│   ├── instructors.csv         # Instructor profiles, assignments, and preferences
│   ├── rooms.csv               # Rooms, capacities, room types, and constraints
│   ├── time_slots.csv          # Weekly timetable slots (days, start/end times)
│   ├── student_cohorts.csv     # Student cohorts and mandatory curriculum
│   ├── constraints.csv         # Formal definitions of hard and soft constraints
│   ├── sample_constraints.json # Machine-readable constraint specification
│   └── <studentid>_timetable.csv # Output schedule generated by studentscheduler()
├── report.md                   # Report template to complete
├── requirements.txt            # Python dependencies (pandas, pytest)
├── Project_Guidelines.md       # Detailed project requirements and marking scheme
└── README.md                   # This starter guide
```

## Getting Started

### 1. Set Up Python Virtual Environment
```bash
python3 -m venv venv
source venv/bin/activate        # On Windows: venv\Scripts\activate
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the Starter Scheduler
```bash
python app.py
```
This executes `studentscheduler(data_dir="data", output_dir="data")`.

## Your Implementation Tasks

1. **CSP Formulation & Data Loading**:
   - Parse datasets from `data/` (`courses.csv`, `instructors.csv`, `rooms.csv`, `time_slots.csv`, `student_cohorts.csv`).
   - Define CSP Variables, Domains, and Constraints.
2. **Backtracking & Heuristic Search**:
   - Implement CSP Backtracking with Minimum Remaining Values (MRV), Degree Heuristic, Least Constraining Value (LCV), and Forward Checking / AC-3.
3. **Local Search & Soft Optimization**:
   - Implement Min-Conflicts local search to minimize soft constraint penalty scores.
4. **Dynamic Timetable CSV Export**:
   - Save your finalized schedule to `<studentid>_timetable.csv` inside `output_dir` (default: `data/`).
   - The generated CSV should contain the columns:
     ```csv
     course_id,room_id,slot_id,instructor_id,cohort_id,day,start_time,end_time
     ```
5. **Report & AI Declaration**:
   - Fill out all sections in `report.md` (Name, UID (netID), UIN, video link, discussion).
   - Generate your [PETRA AI](https://www.petraai.org/student) declaration and save it as `AI_declaration.png`.
